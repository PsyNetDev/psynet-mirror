Fixed one failing network or trial in the background network-growth and trial-finalization checks undoing the work already done for other networks and trials in the same check. Each item now runs in its own database savepoint, so a failure rolls back only that item, which is recorded as an error and marked failed; a lock timeout or deadlock is retried on the next check instead. Code these checks run, such as `grow_network` and `on_finalized`, must not call `db.session.commit()`; it now raises there, as it does when that code runs from a participant's request. The internal `Experiment.isolate_batch_item_failure` is removed.
