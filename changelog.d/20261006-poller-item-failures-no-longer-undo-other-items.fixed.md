Fixed one failing network or trial in the background network-growth and trial-finalization checks undoing the work already done for other networks and trials in the same check. Each item now runs in its own database savepoint, so a failure rolls back only that item, which is recorded as an error and marked failed, and the researcher is notified only once the check's changes are saved; a lock conflict or deadlock is retried on the next check instead. Code these checks run, such as `grow_network` and `on_finalized`, must not call `db.session.commit()` or `db.session.rollback()`: doing so now raises, as it does when that code runs from a participant's request, so the error is recorded and the network or trial is marked failed. The internal `Experiment.isolate_batch_item_failure` is removed.
