Added an optional `update({root, contents, response})` export for JS page modules, so that trial pages sharing one layout can keep a fast task looking like one page. `update` receives the page's `contents`, `response.startClock()` starts the clock for `time_taken`, and `response.answer(value)` submits the answer. See the new "Keeping a task on one page" guide and the `staircase_on_one_page` demo.
