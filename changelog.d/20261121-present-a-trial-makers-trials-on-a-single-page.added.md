Added `LiveTrialGame`, which presents a `StaticTrialMaker`'s trials on a single live-game page, still saving one trial per response. The trial maker creates the trials up front, and the game can send upcoming stimuli to the browser so the next one appears as soon as the participant answers. Pages answer with a `TrialAnswer` message and time responses in the browser with `game.startResponseClock(view)`. `PlayLiveGame` no longer needs `group_type` for one-player games. Trial makers gain `present_trials()`, `get_public_definition(trial)` and `check_performance()`, and `response_timeout_sec=None` turns off the response timeout. See the new "Keeping a task on one page" guide, which also shows how to keep an adaptive task on one page with trial pages that share a `session_id`, and the `live_trial_game`, `live_trial_game_images` and `staircase_on_one_page` demos.
