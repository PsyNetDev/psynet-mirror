JS page modules can now return `{update, cleanup}` from `activate`, so that trial pages sharing one layout can keep a fast task looking like one page. PsyNet calls `update({contents, response})` once the page accepts answers; `response.startClock()` starts the clock for `time_taken`, and `response.answer(value)` submits the answer. See the new "Keeping a task on one page" guide and the `staircase_on_one_page` demo.
