A fixed group that plays a loop of cued rounds can now pass the loop value as `round=`, as in `Trial.cue({"question": i}, round=i)`. Each iteration is then the group's round of that number, so a round's definition can come from the loop. A module whose cues pass `round=` runs once per participant, and its cues raise an error if the participant has run the module before; give each run its own module id. Cueing a round that the group finished without the participant (one whose `GroupBarrier` in `show_trial` has released the group: a cued round closes only then), a round with `round=` again after a later one, or a trial class again in a round the participant played, raises an error; admit players who join during the game at an admission point before each round.
