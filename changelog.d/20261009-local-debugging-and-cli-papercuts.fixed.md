Fixed several local development papercuts. `psynet debug local` no longer reloads when another debug server on the same machine writes its development folder, nor, in a PsyNet or Dallinger source checkout, when files under `tests/`, `demos/` or `docs/` change. With `--no-browsers` it no longer says that recruitment requests will open browser windows. Running `psynet debug` or `psynet test` in a copied experiment that lacks a git repository or `constraints.txt` now says to run `psynet setup`, instead of failing with a traceback. `psynet experiment-variables local` no longer needs an SSH server to be configured, and `--help` works for every subcommand outside an experiment directory. The documented `createdb` command for parallel sessions no longer waits on a password prompt.
