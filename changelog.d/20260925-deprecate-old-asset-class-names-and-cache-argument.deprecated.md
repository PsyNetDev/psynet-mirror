`ExperimentAsset`, `CachedAsset`, and `CachedFunctionAsset` still import from `psynet.asset` but emit a `DeprecationWarning`; use `FileAsset` and `GeneratedAsset`. The old names are aliases for the new classes, so `isinstance` checks and queries behave differently: for example, `OnDemandAsset` and generated assets are no longer instances of `ExperimentAsset`, and `ExperimentAsset.query` now also returns former `CachedAsset` rows. `asset(..., cache=...)` is deprecated and has no effect.
