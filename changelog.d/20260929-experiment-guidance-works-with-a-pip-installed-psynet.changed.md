The experiment `AGENTS.md` and Agent Skills no longer assume a PsyNet source checkout: `AGENTS.md` names `implement-experiment` as the entry point for implementing an experiment, `explore-psynet-repository` reads demo code from GitLab when there is no local clone, and `playwright-testing` defines the few helpers an experiment's tests need instead of citing PsyNet's own test harness. Analysis and design-simulation packages now go in `requirements.txt`, so `psynet setup` keeps them. The default design-simulation criterion divides the margin of error by one reference standard deviation for all scenarios, so noisier assumptions no longer appear to need fewer participants.
