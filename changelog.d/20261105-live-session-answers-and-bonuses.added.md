A live session's game page now answers with the session's outcome, whatever the page sends. Participants can leave the page only after the session's result is saved; if they click Next earlier, the page shows a message and resends the response every second. To make sure every session ends, a live session's `max_duration` now defaults to 10 minutes. Added two ways for a game to pay bonuses: from the outcome, by defining `bonus(outcome, reason, player_id)`, paid once per session as each player leaves the game page, and during play, by calling `queue_bonus(player_id, amount)`. Added `live_session_result(session_id)`, which says how a session ended and whether its record is complete. Added `Page.check_ready_for_response`, with which any page can refuse a response for now, before PsyNet saves anything, by returning `FailedValidation(message, retry_after=seconds)`; browsers and bots resend the response after that many seconds.
