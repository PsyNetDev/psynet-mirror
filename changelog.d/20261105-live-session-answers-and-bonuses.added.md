Added answers and bonuses to live sessions. PsyNet sets a game page's answer to the session's outcome on the server, and ignores what the page sends. A participant can leave the game page once the session's result is saved, and the page then moves on by itself; `LiveSessionControl(..., auto_advance=False)` leaves moving on to the page's JavaScript. If the participant clicks Next earlier, the page asks them to wait and resends the response every second. So that every session ends, a live session's `max_duration` is 10 minutes by default. A game can pay bonuses from the outcome by defining `bonus(outcome, reason, player_id)`, which PsyNet pays once per session as each player leaves the game page, and during play by calling `queue_bonus(player_id, amount)`. Added `live_session_result(session_id)`, which says how a session ended and whether its record is complete.
