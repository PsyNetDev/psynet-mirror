Fixed an intermittent server error that failed a participant waiting at a `Regrouper` when another request released them while their `{SECONDS}` countdown was being computed; a `SimpleGrouper` with `start_short_after` showed such a participant the other waiters' countdown instead. In sandbox and live deployments, barrier waiting messages now show an unknown countdown, with a warning in the log, if the release estimate fails; tests, `psynet debug local` and `psynet test local` still raise the error.
