Each `psynet performance-test` run's summary now reports the server's capacity: the largest tested number of bots with no errors, a 95th-percentile response time under `--max-p95-ms` (default 500) and a 95th-percentile async-process queue wait under `--max-queue-p95-s` (default 5), counting processes still queued when the test ends. Once a larger count exceeded the limits, the summary names the limit it exceeded and suggests a `max_concurrent_participants` of 80% of the capacity. Tests whose bots didn't all start within the measurement window count as exceeding the limits, and async processes left queued by one test are given time to start before the next.
