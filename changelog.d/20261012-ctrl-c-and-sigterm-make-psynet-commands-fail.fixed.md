Ctrl-C and SIGTERM no longer make `psynet` commands that load the experiment, such as `psynet test local` and `psynet performance-test local`, exit silently with status 0: Ctrl-C prints `Aborted!` and fails, and SIGTERM runs the command's cleanup and exits with status 143. The isolated test environment passes SIGTERM on to the test and never exits with 0 after an interrupt, and `psynet performance-test ssh` restarts the app containers it stopped when it gets SIGTERM. Dallinger's web, worker and clock processes still exit with status 0.
