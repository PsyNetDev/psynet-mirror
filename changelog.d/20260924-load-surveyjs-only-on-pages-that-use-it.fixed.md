Timeline pages now load the 8 MB SurveyJS library only when they contain a `SurveyJSControl`. Previously every page waited for it, which could leave buttons disabled for minutes on slow connections. Custom templates that use `Survey` without `SurveyJSControl` must list `/static/scripts/survey-jquery/survey-jquery.js` in `js_dependencies`. jQuery plugins loaded through `js_dependencies` now also stay registered on full page loads.
