`VocabTest` now downloads the font it uses to draw word images into a per-user `psynet-fonts-<uid>` folder in the system's temporary directory, instead of the experiment's `static/fonts/` folder, where it showed up as an untracked file and was deployed for no reason. A failed download now raises an error instead of saving the error page as the font. You can delete a `static/fonts/GoNotoKurrent-Bold.ttf` left by an earlier version.
