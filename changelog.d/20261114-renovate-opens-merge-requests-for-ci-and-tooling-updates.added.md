Added a Renovate configuration that opens weekly merge requests updating the Docker, Redis, Node, Chrome and Playwright versions in CI, the pre-commit hooks, and the GitHub Actions in the experiment template's `.github/workflows/test.yml`; Python and Postgres versions are still updated by hand. Renovate's merge requests skip the changelog fragment check, except those for the experiment template, which reach experiment authors through `psynet scripts update`. CI's Redis service is now pinned to `redis:8.10`, the version `redis:latest` currently points to, instead of following `latest`.
