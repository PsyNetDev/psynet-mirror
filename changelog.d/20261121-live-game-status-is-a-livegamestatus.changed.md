A live game record's `status` is now a `LiveGameStatus` (`NOT_STARTED`, `RUNNING`, `ENDED` or `FAILED`), and `psynet.live_game` has constants for its end reasons: `FINISHED` and `FAILED` alongside `TIMEOUT` and `PLAYERS_LEFT`. If you used live games from an unreleased PsyNet, replace `game.finished` with `game.end_reason == FINISHED`, or with `game.status == LiveGameStatus.ENDED` to accept a game that ended for any reason, and rename `NOT_STARTED` to `NOT_STARTED_MESSAGE`.
