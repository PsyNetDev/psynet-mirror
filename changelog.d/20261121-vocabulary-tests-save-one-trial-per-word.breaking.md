WikiVocab and BibleVocab now present each form on a single page and save one trial per word shown, instead of one trial per form. The constructors still take the number of forms, their size and the per-form screening thresholds. In new exports, read the participant's real or fake choice from each trial's `answer` and the response time in seconds from `time_taken`. Within each `module_state_id`, `position` gives the order of presentation and trials with the same `node_id` are repeats of the same word. Data collected with earlier versions keep their per-form answer lists. Word images are now generated on demand from node assets.
