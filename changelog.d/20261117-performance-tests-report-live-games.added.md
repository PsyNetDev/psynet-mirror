`psynet performance-test` reports how an experiment's live games kept up, in a new *Live games* section: for each game, the games played and failed, how long the game runner's passes took, and the 95th-percentile delay of its ticks and of players' messages, with how busy the game runners were. A test now fails if a game's p95 tick or message delay is over 100 ms, or if more than 1% of live games fail. `LocalGame.time_play()` times a game's code, without a server, and estimates how many games one game runner can play at once.
