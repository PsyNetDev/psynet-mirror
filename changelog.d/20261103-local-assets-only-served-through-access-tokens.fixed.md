`LocalStorage` no longer links `static/assets` to the asset storage folder, and removes such a link left by an earlier version when the experiment launches. `psynet scripts prune` removes such a link too, but no longer deletes a real `static/assets` directory, which is now treated as the author's own. The link let anyone who knew an asset's SHA-256 digest (for example of a published stimulus file) download it from `/static/assets/objects/sha256/<digest>` without its access token; assets are now served only through `/asset/<access_token>`. Locally stored assets are also served with the content type of their extension (for example `image/png` for a `.png` asset) rather than `application/octet-stream`. Every `/asset/<access_token>` response except a PDF, which Chrome's built-in viewer would not display, also sends `Content-Security-Policy: sandbox`, and HTML, XHTML, SVG, XML and JavaScript assets are sent as downloads (`Content-Disposition: attachment`), so an uploaded file with such an extension cannot run as a page on the experiment's origin; assets still work as `img`, `audio` and `video` sources.
