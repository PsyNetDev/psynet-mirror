CI pipelines now finish in about 8 minutes instead of 17–21. Pytest shards are balanced using recorded test durations (`ci/test_durations.json`), and each of the twelve shards runs two tests at once, each with its own database, Redis server and port (`psynet dev ci run-tests`). Each Playwright job now runs as three duration-balanced shards (`psynet dev ci playwright-files`). Test jobs pull a weekly shared CI image from the container registry instead of building it (`ci/ci-image.sh`), run Postgres without durability (`fsync=off`), and on feature branches no longer run the null translator.
