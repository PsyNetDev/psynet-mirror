CI pipelines now finish in about 11 minutes instead of 17–21. Pytest shards are balanced using recorded test durations (`ci/test_durations.json`), and each shard runs two tests at once, each with its own database, Redis server and port (`psynet dev ci run-tests`). Each Playwright job now runs as two duration-balanced shards (`psynet dev ci playwright-files`), and feature-branch test jobs no longer run the null translator.
