Async jobs must now say whether they are CPU-heavy, so that CPU-heavy ones run in CPU workers: pass `cpu_heavy=True` or `cpu_heavy=False` to each `WorkerAsyncJob` and `AsyncCodeBlock`, and set `async_post_trial_cpu_heavy` on each trial class that defines `async_post_trial`. Recording trials such as `AudioRecordTrial` declare `True` already. Without the declaration, PsyNet raises an error that explains the choice; see "Upgrading to PsyNet 14".
