Async jobs must now say whether they are CPU-heavy, so that CPU-heavy ones run in CPU workers: pass `cpu_heavy=True` or `cpu_heavy=False` to each `WorkerAsyncJob` and `AsyncCodeBlock`, and set `async_post_trial_cpu_heavy`, `async_post_grow_network_cpu_heavy` or `async_on_deploy_cpu_heavy` on each trial, network or node class that defines the matching hook. Recording trials such as `AudioRecordTrial`, and media imitation-chain and media Gibbs nodes, declare `True` already. Without the declaration, PsyNet raises an error that explains the choice; see "Upgrading to PsyNet 14".
