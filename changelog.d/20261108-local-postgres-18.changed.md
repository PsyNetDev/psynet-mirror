`psynet services ensure` and the local CI scripts now run PostgreSQL 18 (`postgres:18-trixie`) instead of PostgreSQL 12, which no longer gets security fixes, matching `dallinger docker start-services` in Dallinger 13.1, which PsyNet now requires. PostgreSQL 18 can't open the old data, so an existing `dallinger_postgres` container that runs PostgreSQL 12 is replaced and the local database starts empty in the new volume `dallinger_postgres18`. The old data stays in the `dallinger_postgres` volume; remove it with `docker volume rm dallinger_postgres` once you no longer need it.
