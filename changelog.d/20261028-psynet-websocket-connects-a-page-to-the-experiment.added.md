`psynet.websocket` lets a timeline page and the experiment send each other messages while the page is open. A page sends with `send(type, message)`, which the experiment's `handle_websocket_message` receives on the `psynet` channel, and receives the experiment's messages of a type with `handle(type, callback)`. `onConnect(callback)` runs each time the page connects. Only the page the participant is on can connect: once they move on, the earlier page's connection closes, including in other tabs, and doesn't reconnect.
