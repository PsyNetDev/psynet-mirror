`psynet.websocket` connects a timeline page to Dallinger's `/experiment-socket` route, giving a secret page token (`psynet.var.pageToken`) as the connection's scope. `send(type, message)` sends typed messages on the `psynet` channel, `handle(type, callback)` receives the experiment's messages of that type, and `onConnect(callback)` runs on every connect. The connection opens when the page first uses it and closes when the page changes. The token is an HMAC of the page uuid, keyed with `FLASK_SECRET_KEY`, so it can't be worked out from the page uuid. The server accepts a connection only with the token of the participant's current page, and refuses others with close code 1008. Once the participant moves on, the earlier page's open connections, for example in another tab, are told the page has ended and close without reconnecting. One that misses that message is refused when it next reconnects.
