`psynet.websocket` connects a timeline page to Dallinger's `/experiment-socket` route, giving a secret page token (`psynet.var.pageToken`) as the connection's scope. `send(type, message)` sends typed messages on the `psynet` channel, `handle(type, callback)` receives the experiment's messages of that type, and `onConnect(callback)` runs on every connect. The connection opens when the page first uses it and closes when the page changes. The token is an HMAC of the page uuid, keyed with `FLASK_SECRET_KEY`, so it can't be worked out from the page uuid.
