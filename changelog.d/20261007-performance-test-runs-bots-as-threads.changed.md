`psynet performance-test` and `psynet test local --parallel` now run their bots as threads in a single process instead of starting a `psynet run-bot` process for each bot. 200 bots now take about 250 MB of memory and a third of a CPU core, so a local test can simulate hundreds of participants without the bots competing with the server. Performance-test bot output still goes to the bot log file. Experiments whose `run_bot` override takes a `bot` argument now work in performance tests, parallel tests and `psynet run-bot`.
