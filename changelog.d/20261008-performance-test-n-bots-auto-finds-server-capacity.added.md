Added `psynet performance-test --n-bots auto`, which searches for the largest number of bots the server handles with no errors, a 95th-percentile response time under `--max-p95-ms` (default 500), and a 95th-percentile async-process queue wait under `--max-queue-p95-s` (default 5), counting processes still queued when the test ends. The summary of every multi-count run now reports this capacity, the limit that the next count exceeded, a suggested `max_concurrent_participants` of 80% of it, and the 95th-percentile response time and queue wait per bot count.
