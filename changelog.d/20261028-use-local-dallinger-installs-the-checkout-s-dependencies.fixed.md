Fixed `--use-local-dallinger` (in `psynet debug ssh` and `psynet performance-test ssh`) building an image that lacked dependencies added in the local Dallinger checkout, so the app could build and then answer 503. The image now installs the checkout's missing dependencies, keeping the pinned versions that satisfy it. Run `psynet scripts update` to refresh the experiment `Dockerfile`; until then `--use-local-dallinger` stops and asks you to. A PsyNet or Dallinger version mismatch before deploying now shows a short error instead of a Python traceback, and the `SKIP_VERSION_CHECK` message names both packages.
