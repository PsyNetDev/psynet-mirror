Barrier instances now persist versioned declarative specifications instead of complete Python objects. Custom release state must use JSON-compatible values, supported callables, importable classes, or persisted ORM references; nested or otherwise non-importable classes are rejected when the instance is stored. ``Markup`` ``content`` round-trips instead of being saved as a plain string. Waiting pages and hold-page construction stay on the live timeline object. Scalar fields such as ``content`` and ``max_wait_time`` are restored, so release callbacks may still read them from reconstructed ``barrier`` objects. ``SimpleGrouper`` auto-ids now include the initial group size (``{group_type}_grouper_{size}``). Sequential groupers that share an ID must have the same release behavior; a timeline that reuses one ID with different behavior is rejected at construction.
