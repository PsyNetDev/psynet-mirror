A live session's game is a `LiveSession` subclass, and each kind of message its pages send is a `LiveMessage`, a Pydantic model with an `apply` method. PsyNet checks a message's fields before `apply` runs and rejects a message that doesn't match. A field can have any type Pydantic reads from JSON, such as a tuple, an enum, a datetime or a Pydantic model. The game state holds only JSON values: PsyNet converts what `initial_state` returns, and what a message's `apply` or the game's `tick`, `on_join` or `on_leave` stores, to JSON when the method returns, so a tuple is read back as a list and an enum member as its value. A game with a very large state can turn the conversion off with `convert_state_to_json = False` and store only plain data itself. PsyNet adds every `LiveSession` subclass to the experiment's `realtime_games`, so experiments don't list them.
