`grow_network`, `finalize_trial` and code that runs while a trial is prepared (such as `select_node`, `on_trial_created` and `Trial.finalize_definition`) now raise an error if they call `db.session.commit()` or `db.session.rollback()`. These hooks run inside the participant's response transaction, so committing there released its row locks and could save half-finished work. Use `db.session.flush()` when you need database IDs.
