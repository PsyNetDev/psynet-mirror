Local launches, `psynet test local` and `psynet audit simulate` no longer stop other experiments' processes on the same machine. Leftover `dallinger_heroku_*` workers are stopped only if they use the current `DATABASE_URL` (their `heroku local` supervisor then exits by itself), the test fixture no longer runs `pkill -f heroku`, and Chrome and chromedriver cleanup is limited to the browsers PsyNet's test driver started. PsyNet now finds these workers with Dallinger's `dallinger.heroku.tools.local_worker_processes()`, so it requires a Dallinger version that includes it.
