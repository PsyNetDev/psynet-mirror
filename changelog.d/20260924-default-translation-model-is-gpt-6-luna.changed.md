`psynet translate` now uses `gpt-6-luna` instead of `gpt-4o` by default, which gave better translations in a blind comparison at about a twentieth of the price. `openai_default_temperature` is no longer set by default, because `gpt-6-luna` only accepts the model's own temperature; set it only when you use a model that accepts it, such as `openai_default_temperature = 0` with `openai_default_model = gpt-4o`. Configured temperatures must be numbers from 0 to 2. A config that still sets `openai_default_temperature = 0` keeps working: PsyNet prints that `gpt-6-luna` rejects it and ignores it. Retries of a failed request raise the temperature to 0.7 only when one is configured; otherwise they rely on the model's default temperature to give a different reply.
