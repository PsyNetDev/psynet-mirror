`psynet translate` now uses `gpt-6-luna` instead of `gpt-4o` by default, which gave better translations in a blind comparison at about a twentieth of the price. `openai_default_temperature` is no longer set by default, because `gpt-6-luna` only accepts the model's own temperature; set it only when you use a model that accepts it, such as `openai_default_temperature = 0` with `openai_default_model = gpt-4o`.
