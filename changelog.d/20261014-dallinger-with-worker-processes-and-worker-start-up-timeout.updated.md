PsyNet now needs a Dallinger version with the `worker_processes`, `worker_greenlets_per_process` and `web_processes` settings, which the performance test's worker advice reads, and with `worker_startup_timeout`, which lets an async worker that hangs at start-up after a database reset exit so that Docker starts it again. `psynet debug local --legacy` passes its gunicorn process count as `web_processes` instead of the deprecated `threads`.
