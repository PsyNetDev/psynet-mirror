Added `psynet docs`, which reads the documentation for the installed PsyNet version from disk, without the experiment runtime or a network connection. `psynet docs show code/participants/payment` prints a page, and `psynet docs path` prints the folder so coding agents can search every page at once, for example with `rg -n -i "bonus" "$(psynet docs path)"`. Release packages now include the documentation as plain text, and a PsyNet source checkout uses `docs/` directly. The experiment `AGENTS.md` and the Agent Skills now tell agents to read the documentation this way.
