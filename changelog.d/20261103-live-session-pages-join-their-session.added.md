A live session's game page is a `ModularPage` with a `LiveSessionControl`, given the id of the `LiveSessionInitializer` that started the session. The page's JavaScript plays through `psynet.liveSession`: `send(type, message)` sends the game a message, and `onView`, `onRejected`, `onEnded`, `onResultSaved` and `onRefused` receive its views, rejections, ending and a refused connection. `hasSession` says whether the participant's group started a session there. Prompts and controls can add page variables that depend on the participant with `get_render_js_vars(experiment, participant)`, read each time the page renders.
