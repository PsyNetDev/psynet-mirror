Lucid termination no longer commits the participant's failed status before calling Lucid; the termination is saved as soon as Lucid confirms it. The early-exit path now calls `terminate_participant(..., raise_on_error=True)`, and the private `_terminate_participant` method is gone, so subclasses that customise Lucid termination should override `terminate_participant`. PsyNet's internal helper for saving external-call state now raises inside a database savepoint, where it could not make the record durable.
