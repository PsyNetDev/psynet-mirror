Fixed remote launches (`psynet deploy ssh`, `psynet deploy heroku`, `psynet debug ssh` and `psynet debug heroku`) silently wiping local data. They now say which local database and Redis they will clear, and ask first if a local PsyNet server is running or the local database has participants; pass the new `--yes` option to skip the question, which is required in non-interactive sessions. `--update` launches no longer touch the local database, Redis or local servers. `psynet deploy heroku --docker` no longer runs a second, non-Docker deploy afterwards.
