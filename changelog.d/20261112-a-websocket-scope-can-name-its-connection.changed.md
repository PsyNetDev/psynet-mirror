`Experiment.accept_websocket_connection` now also accepts a participant's `websocket_scope` followed by a `.` and a name for the connection, of up to 64 letters, digits and dots. It accepted only the token itself. A live session's game page sends such a scope, because Dallinger's real-time engine tells a participant's open pages apart by their scopes, and every page that sends the token alone counts as one. A directed message sent with the token as its scope still reaches only the connections that sent the token alone, so PsyNet's own messages to a participant don't go to game sockets.
