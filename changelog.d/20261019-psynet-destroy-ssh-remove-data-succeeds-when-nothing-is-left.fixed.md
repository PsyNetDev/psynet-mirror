`psynet destroy ssh <app> --remove-data` now succeeds, saying "Nothing left to delete", when the app and its data are already gone, for a single app as well as several. The reminder to export an app is no longer shown when nothing is going to ask about its data (with `--remove-data --yes` or `--keep-data`) or after you decline destroying an app with pending async jobs; with `--remove-data`, it now comes before the confirmation, which says that the data is deleted too. The *Ready* summary of `psynet deploy ssh` and `psynet debug ssh` names the deployed Docker image, and its log viewer row says that the password is saved in `launch-info.json`.
