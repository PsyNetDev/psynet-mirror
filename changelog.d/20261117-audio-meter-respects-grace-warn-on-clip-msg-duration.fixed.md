- Fixed `AudioMeterControl` ignoring its `grace`, `warn_on_clip` and `msg_duration` settings in the browser. The "Too quiet!" and "Too loud!" warnings used hard-coded 1.5 s and 0 s grace periods (so `TappingAudioMeterControl` and the REPP prescreens' 0.2 s grace for loud input had no effect), `warn_on_clip` was never consulted, and warning messages were reset without waiting for `msg_duration`. Grace periods now count from the first microphone reading, so the meter no longer warns before any audio has arrived. Calibration sliders are now read as numbers.
