Added ``psynet deploy ssh --ingress`` for optional per-app Cloudflare tunnels, ``psynet hibernate ssh`` / ``psynet awaken ssh``, automatic wake-before-export, and ``--use-local-dallinger`` to bake an unreleased Dallinger checkout into the experiment image (the experiment Dockerfile force-reinstalls a staged wheel after ``COPY .`` with ``--no-deps``; deploy aborts if a local Dockerfile omits that after-COPY step). PsyNet records ``kind=psynet`` monitoring metadata in the Dallinger deployment manifest.
