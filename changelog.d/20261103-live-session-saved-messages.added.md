A live session's messages can be read back from its record: `RockPaperScissors.saved_messages(session_id)` returns all of a session's messages, and `Choose.saved_messages(session_id)` those of one message type, in the order the game applied them. Each is a `SavedMessage` with the message, its sender, whether the game accepted or rejected it and why, and when it arrived, as a session time and as the server's local time. A message that can't be read as one of the game's message types, such as one rejected for its fields or saved before its type changed, has `message` `None`, and its `payload` holds what the page sent.
