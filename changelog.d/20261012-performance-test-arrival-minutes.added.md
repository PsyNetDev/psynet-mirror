Added `--arrival-minutes` to `psynet performance-test local`, `ssh` and `psynet audit performance-test`, which spreads each test's bots evenly over that many minutes, as participants arrive while a study is open. With `--n-bots auto` it applies only to the validation test, so the search's tests stay short, and must be shorter than the longest validation test: an hour, or `--duration-minutes` if that is longer. It can't be combined with `--stagger`.
