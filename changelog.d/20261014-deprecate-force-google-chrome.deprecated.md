Deprecated `force_google_chrome`; use `browser_capabilities` instead. A deprecation warning is now emitted when `force_google_chrome = true` is set. Also flipped the default to `False` (most experiments don't need Chromium-only behaviour), widened semantics to include all Chromium-based browsers (Edge, Brave, Opera), and removed `min_browser_version` (the `css_has` feature-detect provides an equivalent floor).
