The stock experiment `.gitignore` now ignores `static/fonts/GoNotoKurrent-Bold.ttf`, the font `VocabTest` downloads to draw its word images, so it no longer shows up as an untracked file, and deploys and exports no longer warn that it is uncommitted. Deployments still include it, because `deploy.toml` chooses the deployed files. Run `psynet scripts update` to refresh an existing experiment's `.gitignore`. `VocabTest` now also raises an error when the font download fails, instead of saving the error page as the font.
