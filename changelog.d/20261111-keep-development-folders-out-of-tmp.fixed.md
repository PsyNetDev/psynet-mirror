Fixed `psynet debug local` restarting, and taking over a second per check, whenever a Python file changed anywhere in `/tmp`, such as another PsyNet checkout. Development folders now default to `/tmp/psynet_develop/dallinger_develop` (and `/tmp/psynet_develop/dallinger_develop_<port>` with `--isolated`), so the auto-reloader no longer scans all of `/tmp`. Every user on a machine can create development folders there, as in `/tmp`. If you set `dallinger_develop_directory` yourself, put it inside a folder of its own. Run `psynet scripts update` in existing experiments so that the VS Code debugger configuration in `.vscode/launch.json` uses the new folder.
