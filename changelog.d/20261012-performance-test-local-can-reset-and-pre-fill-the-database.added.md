Added `psynet performance-test local --reset-database`, which starts every test from the same database: it takes a snapshot of the experiment's database before the first test and restores it, with the server restarted, before each later test, so that the tests of `--n-bots auto` compare load rather than amounts of data. `--prefill-participants N` (with `--prefill-bots` for how many run at once) first runs N bots through the experiment without pauses so that every test starts with that much data, and `--keep-snapshot` and `--from-snapshot` let later runs reuse the pre-filled snapshot. The JSON output records whether the database was reset or pre-filled and the snapshot's row counts, and the capacity summary suggests `--reset-database` when tests started with different amounts of data.
