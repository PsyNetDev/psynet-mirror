After a `psynet performance-test ssh --reset-database` reset, PsyNet waits up to 180 s for the app's workers to register with RQ, printing how many have registered from 20 s on; if one doesn't, the error names it and gives the `docker compose restart` command, instead of showing a traceback. Dallinger's `worker_startup_timeout` (Dallinger PR #10086) makes a worker that hangs at start-up exit so that Docker starts it again. A failed reset, including the first one, and a failure to start the app's server processes again afterwards now end the run with an error message rather than a traceback. `performance-test ssh` and `performance-test local` now write `--json-output` after every test, replacing the file atomically, so a run that crashes, is interrupted or fails in its cleanup keeps the tests that finished; `finished_at` is null until the run ends.
