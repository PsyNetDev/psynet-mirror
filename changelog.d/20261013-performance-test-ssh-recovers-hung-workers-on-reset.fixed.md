`psynet performance-test ssh --reset-database` now restarts a worker container that hangs at start-up after a reset instead of ending the run; if it still doesn't register, the error names it and gives the restart command, without a traceback. `performance-test ssh` and `performance-test local` now write `--json-output` after every test, replacing the file atomically, so a run that crashes, is interrupted or fails in its cleanup keeps the tests that finished; `finished_at` is null until the run ends.
