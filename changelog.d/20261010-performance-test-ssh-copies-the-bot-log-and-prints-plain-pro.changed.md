`psynet performance-test ssh` now copies the bot log out of the app's web container when the run ends and prints where it saved it. When its output is not a terminal, as over SSH or when redirected to a file, `psynet performance-test` prints its progress as a new line every 30 seconds instead of redrawing one line with carriage returns. Each test's report lists what made bots fail, and labels its request error count as the errors the server logged.
