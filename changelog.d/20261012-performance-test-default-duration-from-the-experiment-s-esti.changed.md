Changed `psynet performance-test` so that, without `--duration-minutes`, each test lasts 1.5 participant sessions (the timeline's estimated duration times `--time-factor`, rounded up, at most 30 minutes), and each test of a `--n-bots auto` capacity search lasts one session, at most 5 minutes, so that a search takes at most about an hour. The suite header and the audit's performance-test options show the estimated session length, and the header warns when a single-count test is shorter than one session, because such a test only sees the start of the study.
