Upgraded the jQuery that PsyNet timeline pages load from 3.7.1 to 4.0.0, and the bundled jQuery UI from 1.12.1 to 1.14.1. The Lucid dashboard no longer loads a second jQuery on top of the one Dallinger's dashboard provides. Custom JavaScript that uses utilities jQuery 4 removed (for example `$.trim`, `$.isArray`, `$.isFunction` or `$.parseJSON`) must switch to native JavaScript, and templates that link `/static/scripts/jquery-3.7.1.min.js` must link `jquery-4.0.0.min.js` instead. See step 3 of the PsyNet 14 upgrade checklist.
