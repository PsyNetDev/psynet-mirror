When a participant rejects consent, the recruiter's platform calls (Lucid termination and the recruiter's `after_rejected_consent` hook, which reports the outcome for Lab Recruiter) now run in a background worker while the participant sees "Please wait while we record your choice...", instead of inside the participant's web request. If the worker has not finished after 60 seconds, the participant moves on to the debrief page and the researcher is notified. `after_rejected_consent` therefore no longer runs as a timeline step.
