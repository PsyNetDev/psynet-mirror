Added `psynet debug local --isolated`, which runs the debug server on a free port with a temporary database and Redis of its own, like `psynet test local`, so it can run alongside another local debug server and tests. It prints an `export` line that points other local commands, such as `psynet export local`, at its data. The database and Redis are removed when the server stops, so export any data you need while it runs. `psynet debug local` now also refuses to start in a directory that another `psynet debug` serves.
