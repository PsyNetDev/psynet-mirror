Added `psynet debug local --isolated`, which runs the debug server on a free port with its own database and Redis server, so it can run alongside other local debug servers and tests. It prints an `export` line for other local commands, and local commands run in its directory refuse to run when they would read a different database. Its database stays after it stops, and a later `--isolated` server for another experiment directory leaves it alone; without the `export` line, local commands in the directory print it. When it stops, it says so and prints the line again.
