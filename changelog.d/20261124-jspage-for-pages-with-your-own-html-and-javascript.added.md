Added `JSPage`, a page written as your own HTML and one JavaScript module whose `update()` receives the page's `contents` and a `response` handle to answer with. It suits one-off pages, such as a custom form checked by `validate`, as well as trials. Consecutive trials with the same HTML, module and `page_config` share one page that stays on screen, as described in the new "Keeping a task on one page" guide and shown in the new `staircase_on_one_page` demo, which numbers its trials and marks each answer before the next pair appears. `update()` also receives an `AbortSignal`, aborted once a newer trial is shown, so that an `update()` still loading a stimulus can return without drawing it. The docs' "Pages" overview now explains when to use a `ModularPage`, a `JSPage` or a `LiveGamePage`.
