Added `JSPage`, a page written as your own HTML and one JavaScript module whose `update()` draws each trial from its `contents` and answers it. Consecutive trials with the same HTML, module and `page_config` share one page that stays on screen, as described in "Keeping a task on one page". `update()` also receives an `AbortSignal`, aborted once a newer trial is shown, so that an `update()` still loading a stimulus can return without drawing it. This replaces passing such a module to a `ModularPage` through `js_page_modules`: if you used that on a PsyNet 15 pre-release, switch to `JSPage(label, html, module=..., contents=...)`. The docs' "Pages" overview now explains when to use a `ModularPage`, a `JSPage` or a `LiveGamePage`.
