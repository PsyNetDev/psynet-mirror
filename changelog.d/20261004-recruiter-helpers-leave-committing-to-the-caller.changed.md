Lucid's periodic recruiter checks (`run_checks`) and saving a Lucid respondent's termination details no longer commit their caller's transaction, and `GraphChainTrialMaker.create_graph_network` now flushes instead of committing. Commits that save state around a payment or Lucid API call remain, and now also work inside timeline steps; custom recruiters can use `experiment.commit_payment_state()` for the same purpose. An `AttributeError` raised inside a recruiter's `release_participant` is no longer reported as the method being missing.
