Removed the manual-only `tests/local_only` tests, which CI never ran. Their missing-bucket check now runs in CI against the mocked S3, and the `mock_s3_root` mock now raises `NoSuchBucket` when listing a missing bucket, as real S3 does. The `tests/experiments/static_audio` CI test, which runs against the real `psynet-tests` bucket, now sends a unique bot recording per trial, so it uploads recordings to S3 in asynchronous jobs on every run instead of finding identical recordings already stored. Also removed the unused `pytest-test-groups` development dependency.
