Removed the manual-only `tests/local_only` tests, which CI never ran. Their S3 folder-asset and missing-bucket checks now run in CI against the mocked S3, and the `mock_s3_root` mock now raises `NoSuchBucket` when listing a missing bucket, as real S3 does. Setting `PSYNET_TEST_REAL_S3=1` also runs the `boto3` tests in `tests/isolated/test_s3.py` against the real `psynet-tests` bucket; the `aws` CLI test there now runs only with this setting, instead of whenever the `aws` CLI is installed. Also removed the unused `pytest-test-groups` development dependency.
