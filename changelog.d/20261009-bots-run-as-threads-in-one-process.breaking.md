Bots in `psynet performance-test` and `psynet test local --parallel` now share one process and one experiment instance, so bot code that relies on module-level state or on `self` (for example a global counter or `random.seed()`) affects every bot at once. Store per-bot traits on `bot.var` in `initialize_bot`, and use a `random.Random()` instance instead of seeding the global generator.
