Added a ready step to live sessions. A session starts once every player is ready: a game page says so by itself a moment after it opens, and a bot is ready at once. Until the start, the game rejects messages. If some players aren't ready by the game's `ready_timeout`, which is 60 seconds by default, the session starts without them. A game can set its deadlines in its `on_start` method. A page can disable its controls until the start with `psynet.liveSession.disableUntilStarted`, check `psynet.liveSession.started`, or wait for `onStarted`. A game's state and views must be dicts, and PsyNet adds a `live_session` entry to each, which says who is ready and when the session started. `Ready.saved_messages(session_id)` says when each player became ready. Added `psynet.live_session.testing.start_session`, which starts a session in a test so that the game accepts messages.
