Browsers without CSS `:has()` support are now blocked unconditionally, regardless of the `force_google_chrome` setting. This affects Chrome < 105, Safari < 15.4, and Firefox < 121. PsyNet's own CSS already used `:has()` internally, so these browsers were already broken in practice; this makes the requirement explicit. The `min_browser_version` config key has been removed; the `:has()` feature-detect is the effective version floor.
