``psynet performance-test`` now measures how late the bots in each process run, by timing how long a background thread takes to wake from short sleeps, and reports a test in which the 95th-percentile lag exceeded 50 ms as could not be tested, because its bots then make requests more slowly than participants would. Previously such a test could pass, so ``--n-bots auto`` overstated the capacity of large servers. Each test's results show this lag and the busiest bot process's CPU use, which the JSON output saves as ``tester_lag_p95_s`` and ``tester_cpu_share``.
