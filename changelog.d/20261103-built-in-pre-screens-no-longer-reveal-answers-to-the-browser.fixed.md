Fixed built-in pre-screens that let participants read the correct answer from the page. `LanguageVocabularyTest` buttons now submit the button position instead of `"correct"`/`"wrong1"` (and answers are scored against the position stored on the server), and the stimuli of `LanguageVocabularyTest`, `LexTaleTest`, `ColorBlindnessTest`, `HugginsHeadphoneTest`, `AntiphaseHeadphoneTest` and `BeepHeadphoneTest` are now served through PsyNet under opaque `/asset/<token>` URLs instead of S3 file names that encode the answer; the server fetches the files from `media_url` when a participant requests them. `VocabTest` (including `WikiVocab` and `BibleVocab`) now scores 0 unless the submitted answer covers exactly the trial's items, and its item IDs are random instead of a hash of the word. Custom `LanguageVocabularyTrial` subclasses that relied on the `"correct"` answer value must compare against `definition["correct_answer"]` instead.
