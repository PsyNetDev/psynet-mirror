Fixed built-in pre-screens that let participants read the correct answer from the page. The stimuli of `LanguageVocabularyTest`, `LexTaleTest`, `ColorBlindnessTest` and the headphone tests are now downloaded by the experiment server from an http(s) `media_url` and served under opaque URLs. The experiment server therefore now needs outbound internet access to the stimulus host (S3 by default), where previously participants' browsers fetched the files; if a download fails, the stimulus request returns HTTP 502. `VocabTest` (including `WikiVocab` and `BibleVocab`) uses random item IDs and gives no credit unless the answer covers exactly the trial's items. With `n_trials` above 1, `VocabTest`'s per-trial performance check now scores the latest trial instead of always the first.
