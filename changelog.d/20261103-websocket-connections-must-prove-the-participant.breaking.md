A websocket connection that names a participant, on `/experiment-socket` or on `/chat`, must now send that participant's `websocket_scope` as its scope, or PsyNet refuses it. PsyNet's own sockets do this. Custom page code that opens one should pass the token, for example `dallinger.openExperimentSocket({scope: psynetTemplateData.websocketScope})`. A connection that names no participant is unaffected. Built-in chat rooms (`ChatRoom` with `EnableChatrooms`) now run over checked connections: the sender of each message is the participant whose page sent it, a participant can join only the room their current page shows, and messages, occupancy and history go only to the room's current members. A `WebSocketElt` can opt in to the same guarantee with `requires_checked_connection = True`.
