Added `psynet debug ssh --use-local-psynet`, which builds your editable PsyNet checkout, including uncommitted changes, into the experiment image instead of installing the PsyNet version in `requirements.txt`. It skips the sandbox checks on the PsyNet and Dallinger versions, so bundled demos can be launched on a server without editing `requirements.txt`. Run `psynet scripts update` first in existing experiments, whose `Dockerfile` does not yet install the local wheel. If an interrupted run leaves a `psynet-*.whl` in the experiment directory, every command that builds a Docker image stops and asks you to remove it, so it can't replace the pinned version. When a debug or deploy command stops because PsyNet is not pinned and PsyNet is installed editable, the error suggests this option.
