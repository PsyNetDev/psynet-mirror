Added `psynet debug ssh --use-local-psynet`, which builds your editable PsyNet checkout, including uncommitted changes, into the experiment image instead of installing the PsyNet version in `requirements.txt`. It skips the checks on the PsyNet pin, so bundled demos can be launched on a server without editing `requirements.txt`. Run `psynet scripts update` first in existing experiments, whose `Dockerfile` does not yet install the local wheel. When a debug or deploy command stops because PsyNet is not pinned and PsyNet is installed editable, the error suggests this option.
