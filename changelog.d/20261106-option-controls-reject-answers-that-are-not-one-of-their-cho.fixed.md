`PushButtonControl`, `KeyboardPushButtonControl`, `RadioButtonControl`, `DropdownControl` and `CheckboxControl` now also check the browser's answer before it is formatted, so a tampered answer no longer reaches an overridden `format_answer` (for example one that looks the choice up in a payoff table) and records no response. The participant sees "That option is no longer available. Please reload the page." and PsyNet logs a warning with the page label, the answer and the choices, because choices built from live state (such as the creations of a sync group's members) can change between drawing the page and submitting it. Controls with `restrict_to_choices=False`, including `TimedPushButtonControl`, are not checked.
