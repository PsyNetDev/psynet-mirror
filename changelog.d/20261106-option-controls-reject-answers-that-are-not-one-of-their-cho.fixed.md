`PushButtonControl`, `KeyboardPushButtonControl`, `RadioButtonControl`, `DropdownControl` and `CheckboxControl` now reject a submitted answer that isn't one of their choices, showing "You need to select an answer!" instead of saving it, so a tampered request can't reach code that expects a valid choice. The check runs before the page's own validation, including pages that override `validate`, such as `CountryOfBirth` and `MotherTongue`. Empty selections, radio free text, `TimedPushButtonControl` (whose answer is the event log) and bots that submit a formatted `answer` are still accepted.
