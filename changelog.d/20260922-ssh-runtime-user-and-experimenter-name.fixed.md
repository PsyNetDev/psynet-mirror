SSH deployments record the account that launched the experiment. ``os.getlogin`` had reported the Docker daemon, so ``/health`` showed ``experimenter_name`` as ``root``. The experiment image also lets that account create ``server.log`` without making the shipped source writable. Because the experiment runs as that account, experiment code can no longer write files into ``static/`` at runtime on SSH deployments; write such files to a temporary directory (for example with Python's ``tempfile``) or store them as assets instead.
