The Lucid `/terminate_participant` route now terminates an existing participant only when the request carries that participant's `unique_id`; a Lucid `RID` or `assignmentId` alone is refused with a 403 error. A bare `RID` still terminates a respondent who has no participant yet, as PsyNet's mobile-phone and browser checks on the ad and consent pages need. PsyNet's own pages already send what the route needs; custom code that calls `/terminate_participant` for a participant with only `RID` or `assignmentId` must add `unique_id`.
