Trial makers no longer infer `recruit_mode`: `target_n_participants` now requires `recruit_mode="n_participants"`, and `target_trials_per_node` (or `target_trials_per_condition`) requires `recruit_mode="n_trials"`, otherwise construction raises `ValueError`, as does a `recruit_mode` that is not in `recruit_criteria`. Chain-based and static trial makers now default to `recruit_mode=None`, which leaves recruitment to the rest of the experiment. Fixed `GraphChainTrialMaker` using a type annotation as the default `target_n_participants`.
