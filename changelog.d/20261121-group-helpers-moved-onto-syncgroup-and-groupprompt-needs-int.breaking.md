Moved group helpers that PsyNet 14.0.0 had in `psynet.sync` onto `SyncGroup`: write `group.seats` instead of `group_seats(group)`, `group.reached_barrier_after_time_limit(participant)` instead of `reached_barrier_after_time_limit(participant, group)`, and `group.close()` instead of `close_sync_group(group)`. The old functions are removed. `GroupPrompt`'s `answers` and `highlight` must now be keyed by integer participant IDs: string IDs, which 14.0.0 accepted, raise `TypeError`, so key them by `participant.id` rather than `str(participant.id)`.
