Fixed the deploy-time check that compares installed PsyNet and Dallinger versions with `requirements.txt`: it now reads the active interpreter's package metadata instead of running whatever `pip` is on `PATH`, so it works in `uv` virtual environments without pip and recognises editable installs from Git worktrees. A branch or commit pin now fails with a clear error, instead of being skipped, when the editable install's directory is not the root of a readable Git checkout.
