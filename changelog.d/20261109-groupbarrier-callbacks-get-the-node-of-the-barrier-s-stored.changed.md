`GroupBarrier` `on_release` and `on_dissolve` callbacks now get as `node` the round whose trial the barrier is in, as stored when the members arrived, rather than a node worked out from their current trials. A barrier at the start of a module, or of a later run of the same module (as in a loop around it), gets `node=None`, waits for every member still in this module (including one still finishing the previous run), and doesn't mark the previous module's or run's trials as `"stayed"`; leaving the group there doesn't record an outcome on them either. Module states now store `run_index`, which counts the participant's runs of the module from 1 and appears as a new column in exports.
