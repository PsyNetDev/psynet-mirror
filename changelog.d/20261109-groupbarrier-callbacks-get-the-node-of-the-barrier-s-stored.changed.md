`GroupBarrier` `on_release` and `on_dissolve` callbacks get as `node` the round whose trial every released member is still in, as at a barrier in `show_trial`. At any other barrier, such as one in `show_feedback` or at the start of a module or of a later run of the same module (as in a loop around it), `node` is `None`, `trials` holds each member's current trial, and the release doesn't mark those trials as `"stayed"`; leaving the group in a later module or run doesn't record an outcome on them either. Module states now store `run_index`, which counts the participant's runs of the module from 1 and appears as a new column in exports.
