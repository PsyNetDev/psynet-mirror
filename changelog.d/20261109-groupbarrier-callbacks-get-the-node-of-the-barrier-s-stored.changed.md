`GroupBarrier` `on_release` and `on_dissolve` callbacks now get as `node` the round the barrier is in or after, as stored by the members' cues, rather than a node worked out from their current trials, and `trials` holds `None` for a member whose trial is not on it. A barrier at the start of a module, or of a later run of the same module (as in a loop around it), before the group's first cue there, gets `node=None`, waits for every member still in this module (including one still finishing the previous run), and no longer marks the previous module's or run's trials as `"stayed"`; leaving the group there doesn't record an outcome on them either. Module states now store `run_index`, which counts the participant's runs of the module from 1 and appears as a new column in exports.
