`constraints.txt` now also pins the PsyNet runtime packages that Dallinger doesn't pin, such as `dominate`, `jsonpickle` and `polib`, at the versions PsyNet was tested with. PsyNet reads these versions from `psynet/resources/experiment_constraints.txt` in the release or commit that `requirements.txt` pins, so regenerating `constraints.txt` later no longer picks up newer versions of these packages. The CI Docker image uses the same versions, and maintainers refresh them with `psynet dev ci update-experiment-constraints`.
