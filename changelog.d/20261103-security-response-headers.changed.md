Experiment server responses now send `Referrer-Policy: same-origin`, so participant URLs (which contain `unique_id`) no longer reach third-party sites in the `Referer` header, `X-Content-Type-Options: nosniff` and `X-Frame-Options: SAMEORIGIN`. Other sites can therefore no longer show the experiment in a frame. An experiment that must be framed by another site can override `after_request` and remove `X-Frame-Options` from the response that `super().after_request(request, response)` returns.
