The Heroku CLI is no longer a PsyNet installation requirement, because local servers now run with honcho; you only need it to deploy or manage experiments on Heroku (`psynet deploy heroku`, `debug heroku`, `export heroku` and `destroy heroku`). `psynet deploy heroku` and `psynet debug heroku` now stop early with install instructions if it is missing. The experiment `Dockerfile` and GitHub test workflow templates no longer install it, so run `psynet scripts update` to drop it from existing experiments.
