The Heroku CLI is no longer a PsyNet installation requirement, because local servers now run with honcho; you only need it for `psynet` commands that work with Heroku apps, such as `psynet deploy heroku` and `psynet export heroku`. `psynet deploy heroku` and `psynet debug heroku` now stop before preparing the experiment, with install instructions, if it is missing. The experiment `Dockerfile` and GitHub test workflow templates no longer install it, so run `psynet scripts update` to drop it from existing experiments.
