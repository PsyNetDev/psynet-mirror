Fixed messages and docs that sent users of servers with Cloudflare ingress, such as lab computers, to a Dozzle log viewer that those servers don't have. For such apps, the Slack launch notification and the `psynet destroy ssh` and `psynet performance-test ssh` error messages now give the `ssh … docker compose logs -f` command instead of the Dozzle URL, and the deployment monitor no longer shows a logs link; the deployment docs say that Dozzle is available with classic ingress only.
