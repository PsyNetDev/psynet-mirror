`NumberControl` now saves the participant's answer as a number: an `int` for a whole number such as `100` and a `float` otherwise, so typing `78.5` saves `78.5` instead of the string `"78.5"`. Code that converts the answer with `float(...)` or `int(...)` still works, but code that compares it to a string, such as `answer == "100"`, must compare to a number instead. `NaN` and infinity are now rejected.
