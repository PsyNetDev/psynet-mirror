`psynet performance-test` now judges `--max-queue-p95-s` only on high-priority async jobs, which participants wait for (local jobs count as high priority). A backlog of low-priority jobs, such as analyses of trials without feedback, is reported but never fails a test or limits the capacity a search finds. In the JSON results, `queue_waits`, with an entry for each priority, replaces `q_delay_p95`.
