Updated dominate from 2.9.1 to 3.1 or later, and removed PsyNet's patch for dominate's Python 3.12 event-loop warning, which dominate 3.1 fixes itself. dominate 3.1 renders `a`, `span` and `sup` as inline elements, so it no longer puts them on lines of their own: sibling spans or links built with dominate, for example `tags.span("A"), tags.span("B")`, now render without a space between them ("AB" instead of "A B"); add the space explicitly where you want one, for example `tags.span("A"), " ", tags.span("B")`. Attributes set to `0`, such as `value=0` or `tabindex=0`, are now rendered instead of being dropped.
