With a Dallinger version that includes [Dallinger PR #10118](https://github.com/Dallinger/Dallinger/pull/10118), `psynet deploy ssh`, `psynet debug ssh` and `psynet performance-test ssh` to a Cloudflare-ingress server now stop with Dallinger's `Error: Cloudflare error: …` message before they start local services, contact the server, reset local data or run `prepare`, if the Cloudflare API token can't be read.
