The command-line reference now lists every `psynet` command, including the Heroku commands, `deploy local`, `prepare`, `load`, `db`, `experiment-variables`, `run-bot`, `stats ssh`, `generate-config` and `rpdb`. The configuration reference covers the remaining keys, such as `debug_recruiter`, the Heroku, Cloudflare and idle-hibernation keys, `prolific_completion_config` and `worker_startup_timeout`, and says that Heroku and the legacy local process manager size their workers with `num_dynos_worker` rather than `worker_processes`. A new API page documents `psynet.exit` (`ExitPlan`, `PaymentDecision` and related classes).
