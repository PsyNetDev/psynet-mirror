Made Python 3.14 the recommended Python version. `psynet setup` creates new virtual environments with Python 3.14, the experiment `Dockerfile` template deploys on `python:3.14-bookworm`, and the documented `uv venv` commands use 3.14. Python 3.11 to 3.13 remain supported. Existing experiments keep deploying on Python 3.13 until `psynet scripts update` refreshes their `Dockerfile`.
