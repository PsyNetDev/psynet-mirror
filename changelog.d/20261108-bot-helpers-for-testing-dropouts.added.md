Added helpers for testing how a group experiment handles dropouts. `bot.drop_out()` leaves the experiment as if the participant returned the study on the recruitment platform, and the default `test_check_bot` accepts bots that did so. `bot.failed` reads whether a bot has failed, and `bot.current_notice` returns the notice its progress bar shows, such as "Your partner is no longer in your group. Please continue.". `bot.expect_failure()` tells the default `test_check_bot` that a bot is meant to fail, `bot.with_participant(function)` calls a function with the bot's participant, for example to read its role, and `bot.send_chat_message(text)` posts to the chat room on its page. `participant.in_sync_group("pair")` tells whether a participant is still in a group of that type. The `synchronous-experiments` skill now asks for a bot test for each kind of dropout; run `psynet scripts update` to get it.
