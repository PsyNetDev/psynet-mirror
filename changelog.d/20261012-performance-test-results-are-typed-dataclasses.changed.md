Each ``psynet performance-test`` result is now a ``PerformanceTestResult`` dataclass in ``psynet.perf_test``, whose fields are the keys that ``--json-output`` and the audit's ``performance.json`` save, in the same order; ``PerformanceTestResult.from_dict()`` reads a saved result. If the async workers cannot be counted, the JSON now saves ``n_rq_workers`` and ``n_rq_job_slots`` as ``null`` instead of leaving them out.
