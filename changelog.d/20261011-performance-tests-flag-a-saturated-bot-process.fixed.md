``psynet performance-test`` now measures how much CPU each process running bots uses and reports a test in which one used more than 70% of a core as could not be tested, because its bots then make requests more slowly than participants would. Previously such a test could pass, so ``--n-bots auto`` overstated the capacity of large servers. The share appears in each test's results and in the JSON output as ``tester_cpu_share``.
