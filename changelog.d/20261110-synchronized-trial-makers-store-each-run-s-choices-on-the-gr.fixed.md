Fixed synchronized trial makers giving members of one group different participant groups or block orders: a newcomer promoted to leader chose new ones, and in a loop a member who looped faster than the others copied the previous run's. The group now stores each run's participant group, block order and current block in `group.var` (under `runs_of_<trial maker id>`, one entry per run); members, newcomers and a promoted leader copy the current run's, and in a loop the whole group starts each run together.
