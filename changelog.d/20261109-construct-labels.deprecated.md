Deprecated labels on timeline constructs: write `conditional(condition, logic_if_true)` instead of `conditional("label", condition, logic_if_true)`, and drop `label=` from `for_loop`, `sequence` and `randomize`. The old forms still work but warn. Nested `for_loop`s no longer need distinct labels. `while_loop` still accepts an optional `label=` that names its timeout failure tag (`while_loop:<label>`); without it the tag uses the name of the condition function, or for a lambda its file and line, such as `while_loop:lambda@experiment.py:42`.
