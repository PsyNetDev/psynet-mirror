Added pseudonyms such as "Blue fox", with an animal icon in the participant's colour, so that participants can tell each other apart without seeing IDs. Chat rooms now label messages and the participant list by pseudonym instead of "Participant 12"; the list shows the participant's own name as "Blue fox (you)". The dashboard's Participants and Database pages show each participant's pseudonym. Use `participant.pseudonym` to show the same names on other pages, `participant.set_pseudonym(...)` to choose one, and a `PseudonymScheme` subclass on `Experiment.pseudonym_scheme` to change the colours, animals, names or icons. Each built-in name is translated as a whole, so that translations can make the colour agree with the animal.
