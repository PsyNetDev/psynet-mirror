Remote launches (`psynet debug ssh`, `psynet deploy ssh`, `psynet debug heroku`, `psynet deploy heroku` and the first deploy of `psynet performance-test ssh`) no longer touch your local database, Redis or local PsyNet servers. They still build the experiment's starting database on your computer, but now in a scratch PostgreSQL database and Redis of their own, which are removed when the build finishes, so a running `psynet debug local` keeps its data and several remote launches can be prepared at once. Because they replace the experiment directory's generated files, remote launches now refuse to start while a local server serves the same directory.
