Changed bot pacing to be more realistic. Bots with a `time_factor` above 0 never submit a page before its new `Page.min_duration`, the earliest time its `submitEnable` event can fire (for example a recording's `duration` or an audio meter's `min_time`). In `psynet performance-test`, each bot's random pace factor is now at least 0.7. Correctness tests with the default `time_factor` of 0 are unchanged.
