Renamed a page's `js_vars` to `page_config`, read in the browser as `psynet.pageConfig` and as `config` in a page module's `activate()`, with `get_page_config()` for components. PsyNet's own state for the page, such as its page UUID, is no longer mixed into it. The old names `js_vars`, `get_js_vars()`, `psynet.var` and `vars` keep working until PsyNet 16; the Python names warn, and `psynet.var` warns when it reads one of PsyNet's internal values; see "What's new in PsyNet 15".
