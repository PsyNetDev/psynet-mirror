Dallinger's `GET /participant/<participant_id>` route now refuses requests from anyone not logged in to the dashboard. In a PsyNet experiment it returned every participant column, including `unique_id`, which is all `/timeline` needs to show a participant's page, and `page_uuid`, which with the participant id is all `/response` needs to accept an answer. Participant ids are sequential, so anyone who could reach an experiment could view and answer any participant's pages.
