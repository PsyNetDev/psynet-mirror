An unauthenticated visitor can no longer read a participant's identifiers through Dallinger's `GET /participant/<participant_id>` or `/recruiter-exit` routes, or through `/response`. `GET /participant/<participant_id>` now requires a dashboard login, and `/recruiter-exit` needs the participant's `unique_id` as well as `participant_id`. PsyNet's Finish button, its redirect for finished participants and, on PsyNet pages, `dallinger.submitAssignment()` include it. Custom code that builds its own `/recruiter-exit` link with only `participant_id` now gets an error page and needs to add `unique_id`. `/response` now rejects an answer from a page other than the participant's current one even when a redirect is queued for them, for example after a sync-group partner leaves. Setting the `protected_routes` config variable now adds routes to the ones PsyNet protects instead of replacing them.
