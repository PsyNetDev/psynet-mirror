An unauthenticated visitor can no longer read a participant's identifiers through Dallinger's `GET /participant/<participant_id>` or `/recruiter-exit` routes. `GET /participant/<participant_id>` now requires a dashboard login, and `/recruiter-exit` needs the participant's `unique_id` as well as `participant_id`. PsyNet's Finish button and its redirect for finished participants include it. Custom code that sends participants to `/recruiter-exit` with only `participant_id`, such as Dallinger's `dallinger.submitAssignment()`, now gets a 403 and needs to add `unique_id`. Setting the `protected_routes` config variable now adds routes to the ones PsyNet protects instead of replacing them.
