The default deployment-plan size limit is now 1024 MB, so a typical stimulus set can ship in `static/` with the experiment image. Before raising `EXP_MAX_SIZE_MB` further, run `dallinger deployment-files list` and exclude anything that should stay local. Heroku deploys remain capped at 500 MB. Invalid `EXP_MAX_SIZE_MB` values now raise a clear error. `psynet.media.static_url_for` builds a `/static/...` URL from a path under `static/`.
