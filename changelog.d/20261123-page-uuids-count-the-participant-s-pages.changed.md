A participant's page UUID (`participant.page_uuid`) is no longer random: it is made from the participant's id, how many pages they have been shown, what the page is and a hash keyed by the participant's `unique_id`, such as `12-7-trial31-3f9c2a1b7d4e6f80`. Page UUIDs still never repeat, and other clients still can't guess them. Code that only compares page UUIDs is unaffected.
