Closed several routes that trusted or revealed information given only a participant's sequential id. `/execute_early_exit_plan` returns a participant's release link only to a request that sends their exit plan's id. `/timeline/progress_and_reward` and `/timeline/arrival_notice` take `uniqueId` instead of `participantId`. The Prolific exit page and the error page's Submit to Prolific button send the participant's `unique_id` to `/prolific-submission-listener`. `/response` refuses a `page_uuid` that isn't a string with a 400 instead of failing with a server error. `/basic_data` refuses every request when no dashboard username or password is configured. The dashboard's export and artifact routes and `/get_participant_info_for_debug_mode` no longer treat a request from a tunnel such as cloudflared as coming from the local machine.
