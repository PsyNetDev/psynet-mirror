Pages that come straight after a page without an answer, such as a run of instruction pages, now have a Back button, so participants can reread the earlier page. The first page of such a run shows it disabled. The earlier page appears at once, without waiting for the server. The button sits just left of Next, which doesn't move. Back never returns to a question, a trial or a page after a code block or condition, and `show_back_button=False` hides it on a page. Going back returns the time credit and progress to what they were before the earlier page was answered, also inside `with_fixed_time_credit` or a `while_loop`. Going back and then forward again stores another response for the earlier page, as any second visit does. An experiment that overrides `Experiment.process_response` must accept the new keyword argument `back` (or `**kwargs`), which PsyNet passes when the participant goes back. The new `back_button` feature demo shows it. See "Going back to the previous page" in the timeline documentation.
