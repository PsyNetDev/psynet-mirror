Pages that come straight after a page without an answer, such as a run of instruction pages, now have a Back button, so participants can reread the earlier page. The earlier page appears at once, without waiting for the server. The button sits just left of Next, which doesn't move. Back never returns to a question, a trial or a page after a code block or condition, and `show_back_button=False` hides it on a page. The new `back_button` feature demo shows it. See "Going back to the previous page" in the timeline documentation.
