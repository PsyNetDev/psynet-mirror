The module details and tooltips on the dashboard's Timeline tab now require a dashboard login. Previously anyone could read module details such as participant counts. The Timeline tab's routes moved under the dashboard (`/dashboard/module`, `/dashboard/module/tooltip`, `/dashboard/module/progress_info` and `/dashboard/module/update_spending_limits`), so the tab also works when the browser logged in with the password prompt that `psynet debug local` shows. Artifact storage also refuses deployment IDs and filenames that are not a single path component (such as `../x`), so dashboard requests can no longer read, write or move files outside a deployment's folder.
