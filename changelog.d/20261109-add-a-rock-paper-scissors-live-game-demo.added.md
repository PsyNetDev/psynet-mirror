Added ``demos/experiments/rock_paper_scissors_live``, in which pairs play two live games of rock, paper, scissors, of five and then three throws, each game on one page. Each game is a cued trial per player: its definition says how many throws the game has and what a throw won pays, its answer is the player's part of the game's outcome, and the trial pays the bonus. The demo uses PsyNet 14's multiplayer features as the other round-based demos do: a ``SimpleGrouper`` forms the pairs, ``Trial.cue(definition, round=...)`` in a ``for_loop`` gives both players a trial in the same round of the pair, the trial class sets ``sync_group_type``, the loop's ``stop_if`` ends the games for a participant whose partner has left, and a ``conditional`` page then tells them why.
