`BotDriver.current_page_label`, `current_page_text` and `current_page_time_estimate` return `None` once the participant has left, instead of raising `KeyError`. The `experiment_status` table no longer stores the launch's `secret`, so database exports and audits don't show it. Deployment IDs replace punctuation in the experiment label with hyphens, so labels such as "The prisoner's dilemma" no longer put apostrophes in launch-data paths.
