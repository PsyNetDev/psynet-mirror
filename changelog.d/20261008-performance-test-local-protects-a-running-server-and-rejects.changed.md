Without `--existing`, `psynet performance-test local` now refuses to start while another server uses its port (read from `config.txt`) or its database, instead of stopping that server and resetting its database. Performance-test options reject impossible values such as `--duration-minutes 0`, a negative `--time-factor` or `--max-p95-ms 0`. `psynet performance-test local` ends by explaining that its numbers apply to this computer and leave out the requests a participant's browser makes for static files and media, and `psynet performance-test ssh` skips the local-computer caveat. The capacity summary warns when starting the bots took more than a quarter of the test, and the bot process raises its open-file limit so that hundreds of bots don't run out of file descriptors. The cross-test summary lists runs by bot count, names its two "vs base" columns, and leaves async queue limits out of the capacity line when no async processes ran.
