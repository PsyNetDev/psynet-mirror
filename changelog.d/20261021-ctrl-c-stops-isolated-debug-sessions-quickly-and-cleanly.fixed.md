Ctrl+C now stops `psynet debug local --isolated` in about 2 seconds instead of about 10, and without the screens of Redis connection tracebacks that the worker and clock printed after the session's own Redis server was stopped too early. When `psynet debug local --isolated` or `psynet test local --isolated` isn't the foreground job of a terminal, for example when an agent runs it, a SIGINT sent to its `psynet` process now stops the session too, instead of leaving the server running.
