Added internal groundwork for asynchronous recording uploads: a bounded browser queue, size-based upload allowances, authenticated receipt, worker validation and deposit, and deadline handling that fails the affected trial while preserving earlier answers. Missing-recording failures release feedback and performance-check waits without bypassing configured performance checks or running late analysis; ordinary analysis-failure feedback is preserved. Chain selection prevents assigning the same failed recording answer to its participant again. Recording controls continue to use the existing upload path until this lifecycle is connected to page submission and trial navigation.

Added timeout callables to `wait_while` and `while_loop`, evaluated once when waiting starts. Dependent recording waits account for upload and processing deadlines. Resolved waits exit without timing out when participants return to inactive tabs.
