Fixed local experiments interfering with each other. Starting or stopping a local experiment now only stops worker processes launched from the same experiment directory, and refuses to reset a database that another running local experiment is using. `psynet debug local` now honours the `base_port` setting in its default auto-reload mode, and `psynet services ensure` only starts the Docker services that are missing and no longer tries to start one on a port already used by another PostgreSQL or Redis install. The troubleshooting docs explain how to run several experiments at once with separate `DATABASE_URL`, `REDIS_URL` and `base_port` settings.
