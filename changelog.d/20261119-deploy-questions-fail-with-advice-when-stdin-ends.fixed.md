A command-line question, such as whether to deploy a development version of PsyNet, now fails with advice when it runs without a terminal and standard input gives no answer, instead of printing only `Aborted!`. For a development PsyNet, the error says to set `SKIP_CHECK_PSYNET_VERSION_REQUIREMENT=1`. The agent instructions and the "Running and debugging" page now say to keep standard input open only for `psynet debug local` and to give other commands `< /dev/null`, because an open but silent standard input made `psynet deploy ssh` wait forever.
