`psynet deploy ssh` and `psynet debug ssh` now end with a short *Ready* summary listing the participant link, the dashboard address and user, where the dashboard password is saved, and the command for following the logs. Deploy output without a terminal no longer includes `stty: stdin isn't a terminal` or an empty asset progress bar, the experiment Dockerfile template uses the exec form of `CMD` (silencing Docker's `JSONArgsRecommended` warning; run `psynet scripts update` to refresh it), and `--use-local-dallinger` says when PsyNet itself passes the checkout to Dallinger as `DALLINGER_SOURCE`. `launch-info.json`, which holds the dashboard password, is now readable only by your user account.
