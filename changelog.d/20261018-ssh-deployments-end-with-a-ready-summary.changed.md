`psynet deploy ssh` and `psynet debug ssh` now end with a short *Ready* summary listing the participant link (or, without one, the recruitment message, such as a new Prolific study), the dashboard address and user, where the passwords are saved, the command for following the logs and, without a Cloudflare tunnel, the log viewer address. With an up-to-date Dallinger, this summary replaces Dallinger's own, so passwords no longer appear in the output of a successful deployment. Deploy output without a terminal no longer includes `stty: stdin isn't a terminal` or an empty asset progress bar, the experiment Dockerfile template uses the exec form of `CMD` (silencing Docker's `JSONArgsRecommended` warning; run `psynet scripts update` to refresh it), and `--use-local-dallinger` says when PsyNet itself passes the checkout to Dallinger as `DALLINGER_SOURCE`. `launch-info.json`, which holds the dashboard password, is now readable only by your user account.
