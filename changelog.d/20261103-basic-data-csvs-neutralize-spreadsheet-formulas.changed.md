Basic data CSV files in exports now prefix `'` to text that starts with `=`, `+`, `-`, `@`, a tab or a carriage return, so that a participant's answer such as `=HYPERLINK(...)` does not run as a formula when the file is opened in Excel. Numbers, and text that reads as a number such as `"-2"`, are unchanged, as are `basic_data.json` and the `database/` table CSVs. The export docs explain how to open the table CSVs safely.
