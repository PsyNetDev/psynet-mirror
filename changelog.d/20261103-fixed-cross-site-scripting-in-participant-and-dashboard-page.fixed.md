Fixed cross-site scripting (XSS) in participant and dashboard pages. Participant pages rendered with translations had autoescaping turned off, so a crafted link to the error page, or text that one participant typed and another saw (for example in chain experiments), could run JavaScript. The ad, consent and Lucid exit pages now write the request's query string and redirect URL as JSON instead of pasting them into JavaScript, and the Basic data, Participants, Timeline and Lucid dashboards escape participant IDs, termination reasons and exported data.
