Added `Trial.time_limit_reached`, a stored column that says whether the trial's latest timed page ran out of time before it was answered. Later untimed pages, pages shown while waiting at a barrier and the trial's feedback pages leave it unchanged. A trial's timed feedback page, such as a notice whose time limit only moves it on, also no longer counts towards `GroupPrompt` showing the participant as having run out of time at the next barrier: if it times out it no longer marks them, and if it is answered in time it no longer hides a time-out on the trial itself. Added `SyncGroup.rounds(module_id)`, which returns a group's nodes for a module of cued trials in round order, also after the group has ended.
