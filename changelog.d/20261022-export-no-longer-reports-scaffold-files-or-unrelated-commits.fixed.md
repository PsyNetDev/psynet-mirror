`psynet export ssh` no longer asks to confirm a project mismatch (or needs `--allow-project-mismatch`) just because the experiment leaves scaffold files such as `Dockerfile`, `test.py` and `AGENTS.md` out of Git, as PsyNet's demos do, or because the repository gained commits that don't change the experiment directory. Deploys no longer warn about those scaffold files as uncommitted changes either.
