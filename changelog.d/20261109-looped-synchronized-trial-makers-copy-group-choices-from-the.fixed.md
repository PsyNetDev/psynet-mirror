Fixed a synchronized trial maker that is repeated in a loop letting members start a new run before their leader, copying the participant group and block position of the leader's previous run, including when the leader was still on the last page of that run. Each module state now stores `run_index`, the participant's run of the module counted from 1. At the start of a later run, members wait until a member of their group, normally the leader, has started the run with the same `run_index`, and copy only from such a run; if no member starts it, as when the leader's loop ended earlier, the wait ends at `sync_group_max_wait_time`. On their first run, newcomers, including one promoted to leader, copy the group's choices from any member already initialized instead of waiting for the leader.
