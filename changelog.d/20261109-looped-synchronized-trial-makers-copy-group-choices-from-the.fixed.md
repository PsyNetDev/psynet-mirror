Fixed a synchronized trial maker that is repeated in a loop letting members start a new run before their leader, copying the participant group and block order of the leader's previous run. Members now wait at the start of each run until a member of their group, normally the leader, has started that run, and copy only from that run. If no member starts it, as when the leader's loop ended earlier, the wait ends at `sync_group_max_wait_time`. Once a member has started the run, newcomers, including one promoted to leader, copy the group's choices from them instead of waiting for the leader.
