Default bot answers on `NumberControl`, `TextControl`, `MonitorControl`, the slider controls, `FrameSliderControl`, `MultiRatingControl`, `RatingControl` and graphics pages now go through the page's and the control's `format_answer`, as browser answers do, so bots save the same type and shape as participants. For example, a `RatingControl` bot now saves the rating (`3`) instead of `{"rating": 3}`, and a page that overrides `format_answer` now formats its default bot answers too. Answers given with `bot_response` or returned as plain values from `get_bot_response` are still saved as given.
