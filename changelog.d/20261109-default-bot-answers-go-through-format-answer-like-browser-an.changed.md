Default bot answers on `NumberControl`, `TextControl`, `MonitorControl`, the slider controls, `FrameSliderControl`, `MultiRatingControl`, `RatingControl` and graphics pages now go through the page's and the control's `format_answer`, as browser answers do, so bots save the same type and shape as participants. For example, a `RatingControl` bot now saves the rating (`3`) instead of `{"rating": 3}`. A page that overrides `format_answer` now formats its default bot answers too, so it must accept them: a `TextControl` page whose `format_answer` returns `int(raw_answer)` now fails in bot tests unless it is given a `bot_response`. The built-in `get_bot_response` methods of these controls now return a `BotResponse` holding the browser's raw answer, so a subclass that calls `super().get_bot_response(...)` should read `.raw_answer` from the result. Answers given with `bot_response` or returned as plain values from `get_bot_response` are still saved as given.
