`psynet debug local` now ends its start-up with a `Ready.` block: the recruitment links, `Dashboard: <url> (user …, password …)` (replacing the `❯❯ Experiment dashboard: …` and `Dashboard user: … password: …` lines) and `Press Ctrl+C to stop.`. With a Dallinger version that has `dallinger.command_line.develop.echo_ready()`, the block also shows where the full log is. Experiment audits redact the password in both formats. The line that tells you how to use an isolated session's data from another terminal now puts the `export …` command on a line of its own, so it is easier to copy.
