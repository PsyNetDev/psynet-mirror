`compile_nodes_from_directory` now requires media under `static/` and stores `/static/...` URLs in the node definition instead of creating assets. Move the files from `data/` to `static/` and pass `self.definition["url"]` (or your `url_key`) to prompts; the old `asset_label` argument is replaced by `url_key`. Media extensions are matched case-insensitively, and nodes are compiled in alphabetical order by participant group, block, and filename.
