Added ``--bot-processes`` to ``psynet performance-test local``, ``psynet performance-test ssh`` and ``psynet audit performance-test``, which spreads the bots over several processes so that large tests are no longer limited to the few hundred requests per second that one process can send. The default, ``auto``, uses one process per 250 bots, up to one per four CPU cores, so tests of fewer than 250 bots still run in one process; with ``--n-bots auto`` it plans for the largest count the search may test. The results and bot log are the same however many processes run the bots; a test in which a bot process stops unexpectedly ends early and counts as could not be tested, as does a test after which a bot process does not report back.
