Added typed PsyNet WebSocket messages with default inbound and outbound persistence in per-message-class tables, plus `@session(...)` and server-message `send(...)` helpers for live-session message handlers. Live-session snapshots now default to subclass SQL columns, can be tailored per participant by overriding `snapshot_state(...)`, use typed start/end snapshot messages for lifecycle transitions, and direct `LiveSession` use remains available through PsyNet's generic `var` store.
