The `psynet performance-test` summary is now an easier-to-read table with one row per test in the order run: bots, bots started, length, a pass/FAIL result, response times, failed requests and bots as counts with percentages, and bots finished. The *largest passing test* and the *validation test* (the long test that `--n-bots auto` runs at the recommended number of participants) are labelled. Only the columns and limits that apply are shown, and the limits are listed once. A short verdict follows: the recommended number of participants at once, the largest passing test and the errors at the next count, and the validation test, with advice under *Notes*. The summary, worker advice and audit page call the confirmation test the validation test. In a terminal the summary is coloured and its text wraps to the terminal width, while the table keeps its full width; otherwise, as in log files, it is plain text.
