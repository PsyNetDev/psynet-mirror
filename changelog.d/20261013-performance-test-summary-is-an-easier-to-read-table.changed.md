The `psynet performance-test` summary is now an easier-to-read table with one row per test in the order run: bots, bots started, length, a pass/FAIL result, response times, failed requests and bots as counts with percentages, and bots finished. The *capacity* row (or *highest passed*, if no test failed) and the *check at the cap* row are labelled. Only the columns and limits that apply are shown, and the limits are listed once. A short verdict follows, starting with the recommended number of participants at once, then the capacity, the errors at the next count and the check at the cap, with advice under *Notes*. In a terminal the summary is coloured and its text wraps to the terminal width, while the table keeps its full width; otherwise, as in log files, it is plain text.
