The performance test summary is now an easier-to-read table: one row per test in the order run, with its length, a pass/FAIL result, failed requests and bots as counts out of the total with percentages, how many bots finished, and labels on the capacity and confirmation rows. Only the columns and limits that apply are shown, and the limits are listed once. A short verdict follows, starting with the recommended number of participants at once, then the capacity, the errors that failed the next count and the confirmation test, with advice under *Notes*. In a terminal the summary is coloured and wraps to the terminal width; otherwise, as in log files, it is plain text.
