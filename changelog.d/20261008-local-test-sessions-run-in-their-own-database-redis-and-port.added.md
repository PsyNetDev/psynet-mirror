`psynet test local` and local `pytest` sessions (from the PsyNet checkout, or in experiments whose `pytest.ini` is up to date via `psynet scripts update`) now run in their own PostgreSQL database, Redis server, web port and development folder, so they no longer reset or stop a running `psynet debug local`, and several test sessions can run at once. If that environment can't be set up, the session stops with an error instead of touching the shared services. Set `PSYNET_TEST_ENVIRONMENT=shared` to use the current services instead; CI is unaffected.
