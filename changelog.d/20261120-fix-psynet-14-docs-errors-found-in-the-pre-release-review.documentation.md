Corrected several statements in the documentation that did not match PsyNet 14: PsyNet no longer bundles jQuery UI; PsyNet ends Cint surveys itself, so completing a survey by hand while participants are still working records them as "Survey Closed"; a second `psynet debug local` refuses to start rather than stopping the first; **Leave** pays on Prolific only once the reward reaches `min_reward_for_paid_early_exit`; recoloring the theme, for example for color studies, also needs the hover, tint, background and dark-palette tokens; the analysis examples read the `exports/latest` folder that `psynet export` writes, which `psynet load` also accepts; and the defaults of `check_dallinger_version` (`False`), `loglevel` (`1`) and `response_timeout_sec` (300 seconds).
