`psynet destroy ssh` asks whether to delete the apps' data on the server (database, Redis and Postgres volumes, `~/dallinger-data/<app>`), and first reminds you to export apps it finds no local export of. For a single app, Dallinger lists the data with its sizes and asks; for several apps, PsyNet asks once for all of them. `--remove-data` and `--keep-data` answer in advance and are required in non-interactive runs; kept data is listed with the command that deletes it. This needs a Dallinger version whose `dallinger docker-ssh destroy` has these options; with older versions, destroying works as before and the two flags are refused. `psynet destroy ssh` and `psynet destroy heroku` now show Dallinger's output directly instead of under a spinner.
