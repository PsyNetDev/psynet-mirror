# README

`asset(...)` is PsyNet's way of declaring files the experiment needs — remote
URLs, local paths, whole folders, or even the output of a slow generation
function. Assets can be scoped to a `Module` so pages receive them via the
`assets` argument, and participant-authored content can be deposited as new
assets at runtime. The demo mixes headphone-check audio, a cached computation,
config text, and saving typed input to a text asset.

## Usage

For instructions on how to run PsyNet experiments like this one, visit the
[PsyNet documentation](https://psynetdev.gitlab.io/PsyNet/).
