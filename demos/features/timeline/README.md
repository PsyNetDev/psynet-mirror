# README

This demo is a walkthrough of PsyNet's core timeline building blocks. Most
experiments are assembled from the same primitives: pages that collect or
display information, `PageMaker`/`CodeBlock` for dynamic logic, and control-flow
helpers such as `conditional`, `switch`, `while_loop`, and `for_loop`.

The pages here are deliberately trivial (favorite colors, random numbers,
counting) so the structure stays easy to read. Use it as a companion to the
Timelines tutorial, or as a cheat sheet when you need to see how branching and
looping fit together in a real `Timeline`.

## Usage

For instructions on how to run PsyNet experiments like this one, visit the
[PsyNet documentation](https://psynetdev.gitlab.io/PsyNet/).
