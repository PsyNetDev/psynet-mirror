# README

`PageMaker` builds pages (or lists of elts) dynamically from participant state.
Here the participant picks how many counting pages to see; later makers mix
pages with `CodeBlock`s and even wrap a `while_loop`. The multiplication feedback uses a nested maker so it reads the number after submission. Refreshing an open page reuses the same visit.

## Usage

For instructions on how to run PsyNet experiments like this one, visit the
