# README

`VideoPrompt` and `VideoRecordControl` cover playback and capture: clipped play
windows, muted video with a separate soundtrack, synced A/V, audio or video
responses after a prompt, and combined camera-plus-screen recording with
deferred playback once assets are deposited.

## Usage

For instructions on how to run PsyNet experiments like this one, visit the
[PsyNet documentation](https://psynetdev.gitlab.io/PsyNet/).
