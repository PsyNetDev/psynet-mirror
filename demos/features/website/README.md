# README

A PsyNet timeline can also behave like a tiny multi-page site: a `while_loop`
plus `switch` re-shows content based on `participant.var.current_page`, and
navigation buttons update that variable. Rewards and the progress bar are turned
off so it feels less like a paid experiment.

## Usage

For instructions on how to run PsyNet experiments like this one, visit the
[PsyNet documentation](https://psynetdev.gitlab.io/PsyNet/).
