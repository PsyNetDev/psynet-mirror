# README

Implements a Genetic Algorithm with People–style prosody loop (see
[Bridging the prosody GAP](https://arxiv.org/abs/2205.04820)): creators re-record
a sentence as if in an imagined situation; raters pick the most emotional
recording. Creators and raters are kept as separate roles to avoid emotion
priming.

## Usage

For instructions on how to run PsyNet experiments like this one, visit the
[PsyNet documentation](https://psynetdev.gitlab.io/PsyNet/).
