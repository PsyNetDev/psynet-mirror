# README

A rule-induction Create and Rate game: creators infer a secret inclusion/
exclusion rule from picnic-style examples; raters judge whether proposed rules
fit. Distinctive twist versus `basic` is rating all creations at once against an
objective rule rather than free-form image descriptions.

## Usage

For instructions on how to run PsyNet experiments like this one, visit the
[PsyNet documentation](https://psynetdev.gitlab.io/PsyNet/).
