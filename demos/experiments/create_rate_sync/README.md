# README

A synchronous create-and-rate game for groups of three: everyone invents a food
item for a shared target, then each person chooses between the other two
creations and sees how the group voted. Each page shows the group as pseudonym
animals with `GroupPrompt`: ticks appear as members finish creating or choosing,
and the results page shows everyone's creation in a speech bubble, starring the
most popular one. Use it when creation and evaluation must happen live within a
sync group rather than via asynchronous Create and Rate chains.
