# README

This demo shows how to design a custom chain trial maker. Chain trial makers are
used for experiments whose state evolves over time as participants contribute —
for example iterated reproduction, serial transmission, or other multi-generation
designs. In this example, each participant reads a short story and recalls it in
their own words; that recall becomes the stimulus for the next person in the
chain. Similar logic could be used whenever one trial's response should define
the next node's definition.
