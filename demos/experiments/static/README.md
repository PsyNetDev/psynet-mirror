# README

Introduces `StaticTrialMaker`: a fixed stimulus set (animals × blocks),
keyboard-friendly ratings, repeat trials, and simple performance scoring. Start
here when trials are independent and the stimulus inventory does not evolve with
responses.

## Usage

For instructions on how to run PsyNet experiments like this one, visit the
[PsyNet documentation](https://psynetdev.gitlab.io/PsyNet/).
