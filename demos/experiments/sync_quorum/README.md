# README

Shows quorum-based waiting: participants do filler animal-rating trials until
enough people have joined, then proceed once the group is quorate. The quorate
page shows who is in the group with a `GroupPrompt`, which updates live as
people join, and as they leave the group by returning the study or failing.
Closing the tab doesn't take anyone out of the group. Copy this when an experiment should not advance until a
minimum group size is present.

## Usage

For instructions on how to run PsyNet experiments like this one, visit the
[PsyNet documentation](https://psynetdev.gitlab.io/PsyNet/).
