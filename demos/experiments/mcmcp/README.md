# README

Markov Chain Monte Carlo with People (MCMCP) maps associations in a stimulus
space by asking which of two nearby options better matches a criterion; the
winner becomes the next state and a small random jump proposes the next
comparison. This toy version asks which of two ages better fits occupations such
as doctor or teacher. Start from it when you want pairwise, proposal-based
sampling instead of continuous sliders (as in Gibbs Sampling with People).
