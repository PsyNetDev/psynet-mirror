# README

Gibbs Sampling with People (GSP) estimates mental representations by letting
participants optimize one stimulus dimension at a time (often with a slider)
while other dimensions stay fixed. Here people match RGB color to target words
such as "tree" or "banana" in across-participant chains. Use this as the
canonical GSP starter before specializing to audio, image, or within-chain
variants.

## Usage
