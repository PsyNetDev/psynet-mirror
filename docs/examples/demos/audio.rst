=====
Audio
=====

This demo walks through several ways to produce and record sound:
JSSynth chords, audio and video prompts, recording controls, and an
audio meter. Run it from ``demos/experiments/audio`` with
``psynet debug local`` and step through each page to see which control
is in use.

Source: ``demos/experiments/audio``
