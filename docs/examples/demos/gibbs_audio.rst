================================
Audio Gibbs Sampling with People
================================

This demo is the audio counterpart of the visual
:doc:`Gibbs Sampling with People <gibbs>` demo. The slider is linked to
a continuous sound space: you supply a Python function that generates
an audio stimulus from a set of parameters. Run it from
``demos/experiments/gibbs_audio``.
