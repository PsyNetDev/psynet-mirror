======================
Music perception track
======================

This track puts the demos, pages and exercises in order for researchers who
run online studies of music perception.

#. Install the tools in :doc:`/install` and create a first experiment with
   :doc:`/quickstart`.
#. Run the ``demos/experiments/hello_world`` and ``demos/features/timeline``
   demos, as described in :doc:`/code/project/creating_an_experiment`. For
   each demo, match the code in ``experiment.py`` to what you see as a
   participant, then change some text and refresh the page.
#. Read :doc:`/design/timeline`, :doc:`/code/writing_a_timeline` and
   :doc:`/code/writing_pages`, then do the :doc:`timeline`.
#. Run ``demos/experiments/audio``, which plays JSSynth chords and records
   audio, then do the :doc:`js_synth`.
#. Read :doc:`/design/trials` and :doc:`/code/writing_a_trial_maker`, then run
   the trial demos in order: ``demos/experiments/trial``, ``trial_2``,
   ``trial_3`` and ``static_audio``.
#. Read :doc:`/code/project/classes_and_sqlalchemy`.
#. Apply a pipeline to your own stimuli: ``demos/pipelines/simple_rating``
   for ratings, or ``demos/pipelines/tapping`` for beat synchronization
   (see :ref:`demos_catalog_pipelines`).

``demos/experiments/vertical_processing`` and the
:doc:`/examples/example_experiments/index` are complete music experiments.
