Dallinger
=========

PsyNet is built on `Dallinger <https://dallinger.readthedocs.io/>`_, a
framework for online network-based experiments. Dallinger provides the web
server, database models for networks, nodes and participants, recruiter
integrations, and deployment tooling. PsyNet adds the timeline, trial makers,
pages, and asset handling on top. A few commands, such as
``dallinger deployment-files list``, are still run through Dallinger directly.
