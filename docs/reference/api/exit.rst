================
Participant exit
================

The plans that PsyNet records when a participant finishes, fails, declines
consent, leaves early or hits a fatal error. To change the **Leave**
confirmation, override :meth:`~psynet.experiment.Experiment.plan_exit`; see
``show_early_exit_button`` in :doc:`/reference/configuration`.
