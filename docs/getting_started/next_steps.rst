Next steps
==========

Once an experiment runs on your computer, the rest of the documentation is
organized around what you do next.

- :doc:`/designing/index` explains the ideas you need to specify an
  experiment and to check an implementation, whether an agent wrote it or
  you did.
- :doc:`/guides/testing/index` covers checking an experiment before anyone
  takes it: simulated participants, performance tests and
  :doc:`experiment audits </guides/project/audit>`.
- :doc:`/running_studies/index` covers putting an experiment on a server,
  recruiting participants and monitoring the study.
- :doc:`/running_studies/reference/data` covers exporting and working with
  the data.

For help with specific tasks, such as adding a screening test or
supporting several languages, see :doc:`/guides/index`.
