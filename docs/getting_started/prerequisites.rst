Prerequisites
=============

This tutorial assumes some familiarity with Python, the Unix command
line, and Git. You also need a local PsyNet install and Google Chrome.

Knowledge
---------

You should be comfortable with these Python features:

- Functions
- Classes and inheritance
- List and dictionary comprehensions
- Decorators
- Imports, modules, and packages

If you are new to Python, start with
`Python's Getting Started page <https://www.python.org/about/gettingstarted/>`_.
Paid courses such as DataCamp and Udemy also cover this material.

You should be able to change directory with ``cd`` and list files with
``ls``. If you are new to the command line, try
`Software Carpentry's Command Line tutorial <https://swcarpentry.github.io/shell-novice/>`_.

At some point you will also need Git. Take an introductory tutorial
early on. For PsyNet-specific Git workflow, see
:doc:`version control with Git </guides/project/version_control_with_git>`.

Software
--------

Install PsyNet for your operating system before continuing; see
:doc:`/getting_started/installation/index`.

Install **Google Chrome**. PsyNet currently only supports Chrome as a
participant browser.
