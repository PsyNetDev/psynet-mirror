Lab research workflow
=====================

Use this section when your experiment already runs locally and you are
getting ready to collect real data. It is a runbook: it covers the
practical steps around a study in the order you are likely to need them,
and links to the :doc:`deployment reference </running_studies/reference/index>`
for detail on servers, deployment commands, data export, and monitoring
tools. Unfamiliar terms are defined in the :doc:`/reference/glossary`.

If you are launching an experiment for the first time, read the core
pages in order:

1. :doc:`prerequisites`: one-time software, account, credential, and
   server-access setup.
2. :doc:`general_deployment_process`: the order of work from design and
   testing through live deployment.
3. :doc:`provisioning`: choosing or preparing the server that will host
   the experiment.
4. :doc:`setting_up_the_experiments`: final checks for configuration,
   recruiter, storage, and testing.
5. :doc:`deploying`: the live deployment command and the final checks
   before real participants arrive.

Then read the pages that apply to your study:

- :doc:`recruiters/index` for Prolific, CINT, or Lab Recruiter.
- :doc:`monitoring_and_managing` while the study is recruiting.
- :doc:`exporting_and_terminating` and :doc:`teardown` before you
  consider the deployment finished.
- :doc:`/running_studies/reference/troubleshooting` and
  :doc:`getting_help` when something does not behave as expected.
