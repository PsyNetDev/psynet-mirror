Auditing experiments
====================

An experiment audit is the document used to review an experiment before
launch. A coding agent creates it while building and testing the
experiment, and records what was asked for, what was built, how it was
tested, and anything still unresolved. The pages in this section describe
the contents of an audit in detail.
