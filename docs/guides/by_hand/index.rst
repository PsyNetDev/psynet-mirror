Building an experiment by hand
==============================

These chapters are for writing PsyNet code yourself rather than through a
coding agent. They start from PsyNet's demos: run one on your computer, apply
a ready-made pipeline to your own stimuli, then copy a demo and change it
into your own experiment.

You'll need some familiarity with Python (functions, classes, imports), the
command line, and Git. If you're new to Python, start with
`Python's Getting Started page <https://www.python.org/about/gettingstarted/>`_.
